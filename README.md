# S3 Fruits Website 🍎🍊🍌

## Project Description

This project is a static fruits website hosted using Amazon S3.

## Technologies Used

- HTML
- CSS
- JavaScript
- Amazon S3

## Features

- Fruits website with multiple pages
- Product browsing
- Shopping cart page
- Checkout page
- Contact page
- Static website hosting using Amazon S3
